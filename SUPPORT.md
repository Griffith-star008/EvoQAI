# Support Policy

## Reporting Issues
If you encounter a bug, have a feature request, or need help integrating the Universal AI Intermediate Representation (UAIR) into your workflow, please open an issue on the GitHub repository.

## Version Support Lifecycle
We follow Semantic Versioning. 
- **Major Releases (e.g., 10.x.x):** Receive active development and feature additions for 12 months.
- **LTS (Long Term Support):** Certain major versions will be designated LTS and receive critical security and bug fixes for 24 months.

## Security Vulnerabilities
Please refer to `SECURITY.md` for our responsible disclosure policy. Do not report security vulnerabilities on the public issue tracker.

## Commercial / Enterprise Support
For enterprise-grade SLAs, distributed cluster deployment assistance, or custom quantum hardware integration, please contact the Principal Architect directly.
