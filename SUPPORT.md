# Support Policy

The AQIP Framework is an open-source research and production platform. This document outlines the expectations for community support and maintenance.

## 1. Issue Tracking
All bug reports, feature requests, and support questions should be opened on the GitHub Issue Tracker.
- Please use the provided Issue Templates.
- Ensure you include a reproducible environment (`benchmark_config.json` and `environment.md`).

## 2. Supported Versions
| Version Branch | Status | Maintenance Window |
|:---|:---|:---|
| `v10.x` | **Current Stable** | Supported until Dec 2027 |
| `v9.x` | Maintenance | Security patches only until Dec 2026 |
| `v8.x` | End of Life (EOL) | No longer supported |

## 3. Response Times (Best Effort)
- **Critical Bugs (Security, Data Corruption):** 72 hours.
- **Normal Bugs:** 1-2 weeks.
- **Feature Requests:** Reviewed monthly during community syncs.

## 4. Contact
For security disclosures, do not open a public issue. Email: `security@aqip-project.org`.
For commercial support or academic collaboration: `maintainers@aqip-project.org`.
